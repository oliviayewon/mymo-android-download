# mymo-android-download
# Mymo 안드로이드 앱

메모를 공유하면 AI가 일정을 분석하고 캘린더 작성 화면으로 연결합니다.

## 설치
1. Mymo-demo.apk를 다운로드합니다.
2. 안드로이드폰에서 파일을 열어 설치합니다.
3. Android 8.0 이상과 인터넷 연결이 필요합니다.

## 사용
1. 삼성 노트에 날짜와 시작·종료 시간이 포함된 메모를 작성합니다.
2. 공유 → 텍스트 파일 → Mymo 메모 정리를 선택합니다.
3. 자동 분석 후 캘린더에서 내용을 확인하고 저장합니다.
4. 일정이 여러 개면 목록에서 하나씩 추가합니다.

정보가 부족하거나 확인이 필요한 일정은 등록하지 않고 안내합니다.
분석 시 공유한 메모가 팀 서버와 AI 제공업체로 전송됩니다.

이 저장소는 시연용 APK 배포 전용입니다.
